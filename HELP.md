# Getting Started

### Reference Documentation
Оркестратор получает заявку на медицинское страхование

Оркестратор вызывает POST /api/v1/external/health-policies

Insurance-service:

Проверяет данные

Рассчитывает премию

Создает полис в статусе DRAFT

Возвращает ID полиса и сумму к оплате

Оркестратор инициирует оплату через платежный сервис

После успешной оплаты оркестратор отправляет событие payment-completed

Insurance-service:

Получает событие

Активирует полис (меняет статус на ACTIVE)

Отправляет событие policy-activated

Оркестратор получает событие и уведомляет клиента
